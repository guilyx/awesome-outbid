# Code of conduct

## The short version

Be decent. This repo is about a genre where people take money from strangers on
the internet; the least we can do is behave well with each other.

## Expected

- Assume good faith, including from people whose board you think is a bad idea.
- Critique mechanics, code, and claims. Not people.
- Disclose your interest when you have one — if a board is yours, say so.
- Accept that "this is a clone with no differentiation" is a technical
  assessment of a listing, not an insult.

## Not acceptable

- Harassment, personal attacks, or sustained hostility toward a contributor.
- Doxxing, or posting anyone's private information.
- Using this repo to run a feud with a competing board.
- Astroturfing: sockpuppet PRs, fake post-mortems, invented numbers.
- Posting listings or links that target a specific individual.

## Reporting

Open an issue if it can be public, or contact the repository owner via their
GitHub profile if it cannot. Reports are handled privately.

Maintainers may edit, close, or remove any contribution that does not follow
this document, and may block accounts that repeatedly ignore it.
